## 📖 免费干货预览（不买也能用）

**写周报公式 1：角色 + 任务 + 格式 + 示例**
```
你是一名资深项目助理，请把我的工作内容整理成周报。
格式：本周完成 / 下周计划 / 风险与求助 三部分，每部分 3 条以内。
参考我的写法风格：【粘贴你上周写的周报 1-2 段】
我的工作内容：……
```

**写周报公式 3：数据填充法**
```
下面是我这周的数据，帮我写成领导爱看的周报：
处理工单 23 个、完成 2 个项目节点、跨部门沟通 6 次、新人带教 3 小时。
请把数据融入叙述，不要罗列数字，突出"结果和价值"。
```

> 好提示词 = 角色 + 任务 + 具体要求 + 输出格式。学会这一条，AI 立刻变好用。
